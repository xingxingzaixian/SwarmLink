## 1. 总体交互框架（界面骨架）

> 细化 PRD 15.1 原型，明确面板、常驻控件与全局状态。

### 1.1 主窗口布局
| 区域 | 内容 | 关键控件 |
|------|------|----------|
| 顶部栏 | 自身昵称、在线状态切换（在线/忙碌/隐身*）、搜索框（联系人/共享/消息） | 状态下拉、搜索输入框 |
| 左侧导航 | 三个 Tab：①在线用户 ②我的群组 ③共享中心 | Tab 切换、未读红点 |
| 中间会话区 | 选中联系人/群组后的消息流 + 输入栏（文本框 + 发送 + 附件 + 表情*） | 消息气泡、时间戳、送达状态图标 |
| 右侧（可选/可收起） | 选中会话的文件传输队列、选中共享的目录树 | 进度条、暂停/取消按钮 |
| 底部浮层 | 全局传输队列（总进度、并发数、网速） | 最小化箭头、全部暂停 |

\* 隐身/表情本期可后置，先标注，不阻塞 MVP。

### 1.2 全局状态指示
- **发现状态灯**（顶部栏右侧）：三态——`同网段已连接` / `跨网段经种子 N/M` / `受限（同网段可用，跨网段失败）`。
- **托盘图标**：双击唤出主窗口；新消息红点 + 角标计数；右键菜单含「打开 / 退出 / 免打扰」。

### 1.3 统一交互约定
- 拖拽：从资源管理器拖入会话区或联系人头像 → 触发发送；拖入共享中心 → 触发发布。
- 右键菜单：联系人（发起聊天 / 发送文件 / 查看共享 / 复制 IP）；共享项（下载 / 复制链接* / 取消共享）。
- 失败统一不静默：任何失败操作必须弹 toast + 写入「事件日志」面板（设置页内）。

## 2. FR-01 主机发现与在线状态（细化）

### FR-01-1 同网段 UDP 广播发现
- **功能描述**：节点启动后在同广播域发 UDP 广播通告自身；收到他人广播即登记。
- **交互步骤**：① 客户端启动 → ② 自动加入广播组 → ③ 周期性发送自身通告（昵称/IP/版本/TCP+UDP 端口/状态/共享摘要）→ ④ 收到对端通告即加入在线列表。
- **界面元素**：无独立界面；反映在左侧「在线用户」列表与顶部发现状态灯。
- **异常与边界**：广播被交换机隔离（跨 VLAN）→ 仅同网段内可见；此时状态灯显示「同网段已连接」。
- **细化验收**：
  - Given 同网段两客户端 A/B，When A 启动，Then B 在线列表在 ≤2s 出现 A（含昵称与状态）。
  - Given A 修改昵称，When 下次广播到达，Then B 列表昵称 ≤2s 更新。

### FR-01-2 跨网段种子两跳发现
- **功能描述**：向 seed 列表节点发 UDP SEED_PROBE，收到 ANNOUNCE；再经 TCP 向种子拉 PEER_LIST，获得跨网段对端地址。
- **交互步骤**：① 读 seed 列表（IP:UDP/TCP 端口）→ ② UDP SEED_PROBE 给每颗种子 → ③ 种子回 ANNOUNCE（含自身及对端摘要）→ ④ TCP 连种子发 PEER_LIST_REQ → ⑤ 种子回 PEER_LIST_RESP（跨网段已知节点列表）→ ⑥ 本地向这些节点发起直连/订阅其广播。
- **界面元素**：设置页「种子列表」显示每颗种子的连接状态（已连接/重连中/失败）；顶部状态灯显示「跨网段经种子 N/M」。
- **异常与边界**：
  - 种子宕机 → 自动尝试下一颗（退避），状态灯降级为「受限」。
  - 所有种子不可达 → 不阻断同网段；提示「跨网段发现受限」。
- **细化验收**：
  - Given 配置 2 颗种子、其一宕机，When 启动，Then 自动使用另一颗完成跨网段发现，状态灯显示 M=2,N≥1。
  - Given 跨网段 C 经同一颗种子注册，When A 拉 PEER_LIST，Then A 在 ≤3s 发现 C。

### FR-01-3 心跳与超时判定
- **参数表（可配，默认值）**：

  | 参数 | 默认 | 说明 |
  |------|------|------|
  | 心跳间隔 | 15s | 广播/通告周期 |
  | 超时阈值 | 45s | 连续 3 次未收到 → 标记离线 |
  | 种子重连退避 | 5s→30s 上限 | 指数退避，封顶 |
  | 共享元数据增量间隔 | 30s | 仅变更时推送（见 FR-14-3） |

- **交互步骤**：后台定时器驱动，无用户操作。
- **细化验收**：Given 节点 B 异常断电，When 45s 超时到达，Then A 列表将 B 标记离线并停止向其投递在线消息。

### FR-01-4 状态广播
- **功能描述**：自身状态（在线/忙碌/隐身）变更即时通告，对端列表状态刷新 <2s。
- **细化验收**：Given A 切「忙碌」，When 通告到达，Then B 列表 A 头像显示忙碌标识 ≤2s。

## 4. FR-03 单聊文字消息（细化）

### FR-03-1 输入与发送
- **交互步骤**：① 选中联系人 → ② 输入栏键入文本（≤5000 字）→ ③ 点「发送」或 Ctrl+Enter → ④ 消息入本地会话流（状态「发送中」）→ ⑤ 经 TCP 直连送达对端 → ⑥ 收到 ACK 回执 → 状态变「已送达」。
- **界面元素**：多行文本框（自动撑高，上限滚动）、字数计数（接近上限变黄）、发送按钮（禁用态当空文本）。
- **异常与边界**：
  - 对方离线 → 转本地缓冲（FR-04），状态显「待投递」（灰）。
  - 直连失败（防火墙）→ 提示失败，状态「未送达」，可手动重试。
  - 超长文本 → 前端拦截，禁止发送并提示上限。

### FR-03-2 送达/已读状态
- **功能描述**：消息气泡右下角状态图标：`⏳发送中 → ✓已送达 → 👁已读`（已读为可选，对方读即回 READ 事件）。
- **细化验收**：Given 双方在线，When 发送，Then 对方 ≤1s 收到；对方打开会话 → 发送端气泡显示已读（若启用）。

### FR-03-3 消息完整性
- **细化验收**：Given 含换行/emoji/特殊字符/超长（≤5000），When 发送，Then 对端完整渲染无截断、无乱码。

## 5. FR-04 离线消息（发送端本地缓冲 + 双在线投递）（细化）

### FR-04-1 本地缓冲队列
- **功能描述**：接收方不在线时，消息写入发送端本地 SQLite/文件队列，标记 `buffered`，不入网络。
- **界面元素**：会话内该消息显「待投递」灰标；会话列表项显示「N 条待投递」角标。
- **参数**：保留期默认 30 天（可配）；超期自动清理并标记「已过期未送达」。

### FR-04-2 双在线投递触发（Flush）
- **触发时机（三个，任一满足即扫描该接收方的缓冲队列）**：
  1. 发送端自身启动 / 从离线恢复在线；
  2. 收到对端 `PRESENCE(online)` 事件（FR-01 状态广播）；
  3. 兜底定时器（默认每 30s）扫描所有 `buffered` 消息。
- **交互步骤**：触发 → 校验「发送端在线 ∧ 接收方在线」→ 逐条重发 → 收到 ACK → 状态 `已送达` → 待投递计数 -1。

### FR-04-3 边界与代价（写入帮助/提示）
- **已知取舍（RK-08/RK-07）**：
  - 发送端在接收方上线期间也离线 → 消息滞留，待双方再次同在线才投。
  - 发送端磁盘损坏/重装 → 缓冲与本地共享配置可能丢失，首启动弹「建议备份本地数据」提醒。
- **细化验收**：
  - Given 接收方离线，When 发 5 条，Then 全存本机，接收方上线前 0 送达。
  - Given 接收方上线且发送端在线，When 缓冲存在，Then 5 条按序送达，角标清零。
  - Given 发送端在接收方上线期也离线，When 双方再次同在线，Then 最终送达。

## 6. FR-05 文件发送（P2P 直连，阻断即失败）（细化）

### FR-05-1 发起与握手
- **交互步骤**（详细握手见 16.3）：① 拖入/选文件 → ② 弹「发送确认」（文件名/大小/对方）→ ③ 确认 → ④ 发起 TCP 直连 → ⑤ 发 FILE_META → ⑥ 接收方 ACK（空间/上限校验）→ ⑦ 分块传输 → ⑧ FILE_DONE + 哈希校验。
- **界面元素**：发送确认弹窗、传输队列项（文件名/进度/速度/剩余时间/暂停/取消）。

### FR-05-2 端口协商与上限
- **功能描述**：直连使用可配置 TCP 端口（默认段内协商，失败回退默认端口）；单文件上限默认 10GB（可配），超限拒绝并提示。
- **细化验收**：Given 双方可达，When 发送，Then 全程 P2P 不经第三方；Given 文件 >10GB，When 选择，Then 前端拦截提示上限。

### FR-05-3 失败明确提示（无兜底）
- **异常与边界**：
  - 防火墙/NAT 阻断 → 直连超时 → 提示「直连失败（可能被防火墙/NAT 阻断），请检查端口或网络」。
  - 对方离线 → 提示「对方不在线，文件未发送（可转离线？本期不支持离线文件，提示手动重发）」。
  - 磁盘不足/文件被占用 → 预检失败，提示具体原因。
- **细化验收**：Given 一方在防火墙后，When 发送，Then 失败弹窗含明确原因，不静默。

## 7. FR-06 大文件断点续传（细化）

### FR-06-1 续传判定
- **功能描述**：重发同文件（同路径+大小+哈希）时，接收方比对已收偏移，从断点继续。
- **交互步骤**：① 发起重发 → ② 发 RESUME_OFFSET 请求（带文件哈希）→ ③ 接收方回已收偏移 → ④ 发送方从偏移续传 → ⑤ 完成后整体哈希校验。
- **界面元素**：续传任务显「续传自 XX%（已传大小）」；临时文件 `.part` 隐藏于下载目录。

### FR-06-2 临时文件与清理
- **异常与边界**：取消/失败 → 保留 `.part`（便于续传）或按设置清理；已完成 → 重命名去 `.part`。
- **细化验收**：Given 已传 40% 断开，When 重发同文件，Then 从 40% 继续，耗时显著低于从零；Given 取消，When 再发，Then 可选「续传/覆盖」。

## 8. FR-07 拖拽批量发送（细化）

### FR-07-1 批量入队
- **交互步骤**：① 从资源管理器多选拖入会话区/头像 → ② 弹「批量发送确认」（文件数/总大小/逐项大小）→ ③ 确认 → ④ 逐项入传输队列 → ⑤ 并发传输（默认 ≤5 路，可配）。
- **界面元素**：批量确认弹窗（可取消单项）、队列总进度条（Σ完成/Σ总量）。

### FR-07-2 文件夹展开
- **功能描述**：拖入文件夹 → 递归展开为文件项（保留相对路径），逐文件发送；接收方按相对路径还原目录。
- **细化验收**：Given 拖入 10 文件，When 确认，Then 队列依次/并发传输，总进度正确，单项失败可单独重试。

## 9. FR-08 传输进度 / 暂停 / 取消 / 重试（细化）

### FR-08-1 进度展示
- **界面元素**：每项显 速度(MB/s)、百分比、剩余时间（EMA 估算）；全局浮层显总网速与并发数。

### FR-08-2 暂停/恢复/取消
- **交互步骤**：暂停 → 停发并保留偏移/`.part`；恢复 → 从偏移续（同 FR-06）；取消 → 清理 `.part`/已收片段，会话标注「已取消」。
- **细化验收**：Given 传输中，When 暂停，Then 停且可恢复；When 取消，Then 无残留临时文件。

### FR-08-3 失败重试
- **功能描述**：失败后任务显「重试」按钮 → 点击触发重连+续传（FR-06）。网络抖动自动重试 ≤N 次（默认 3）后标记失败。
- **细化验收**：Given 传输因抖动失败，When 自动重试≤3 次成功，Then 任务完成；超次 → 标记失败供手动重试。

## 12. FR-11 消息通知（细化）

### FR-11-1 托盘气泡与声音

## 14. FR-13 群组聊天（细化）

### FR-13-1 创建群组
- **交互步骤**：① 左侧「我的群组」+ 按钮 → ② 弹「创建群」窗（群名/选成员/设群主=自己）→ ③ 确认 → ④ 向所选成员发 GROUP_CREATE（含成员列表）→ ⑤ 各成员客户端建群会话。
- **界面元素**：创建群弹窗（成员多选列表含在线状态）、群头像/群名。

### FR-13-2 成员管理
- **功能描述**：群主可邀请（发 GROUP_INVITE）、移除（GROUP_REMOVE，仅群主）；成员可主动退群（GROUP_LEAVE）。
- **界面元素**：群设置面板「成员管理」（角色标识、移除按钮仅群主可见）。
- **细化验收**：Given 群主移除成员，When 生效，Then 该成员不再收后续群消息；Given 成员退群，When 生效，Then 其会话标记「已退出」。

### FR-13-3 群消息投递与群离线
- **功能描述**：发送端向每个在线成员 P2P 直投；离线成员按 FR-04 本地缓冲，待其上线且发送端在线时投递（群规模大时批量+限流，见 RK-06）。
- **细化验收**：Given 5 人群 2 人离线，When 发群消息，Then 在线 3 人 ≤1s 收到；离线 2 人上线且发送端在线后按序收到未读。

### FR-13-4 群文件
- **功能描述**：向群组发文件（目标=groupId），复用 FR-05/06；成员各自 P2P 从发送端拉取（非群主中转）。
- **细化验收**：Given 群内发文件，When 成员下载，Then 各自 P2P 拉取并支持续传。

### FR-13-5 群解散
- **交互步骤**：群主「解散群」→ 二次确认 → 发 GROUP_DISBAND → 所有成员收解散提示且停止路由。
- **细化验收**：Given 群主解散，When 生效，Then 全体成员收提示且不再收群消息；本地群会话标记「已解散（只读）」。

## 15. FR-14 文件共享（细化）

### FR-14-1 发布共享
- **交互步骤**：① 共享中心「发布」→ ② 选目录/文件 → ③ 设共享名 + 可见性（全部/指定人/群组）→ ④ **发布确认弹窗**（明示将被可见的文件范围、数量、总大小、可见性）→ ⑤ 确认 → ⑥ 生成共享元数据（FR-14-3）→ ⑦ 经发现层传播。
- **界面元素**：发布向导（路径选择/可见性下拉/确认摘要）、共享卡片（名/owner/可见性标/文件数）。

### FR-14-2 可见性控制
- **功能描述**：`全部`=任何发现者可见；`指定人`=白名单 id 列表；`群组`=仅该群成员。下载请求校验请求方是否在范围，越权拒绝。
- **细化验收**：Given 共享=指定人且 C 不在名单，When C 请求，Then 被拒并提示无权限。

### FR-14-3 共享元数据格式（详见 16.4）
- **功能描述**：元数据含 share_id、owner、owner_tcp_port、name、visibility、items[{path,name,size,hash,mtime}]、created_at。变更增量传播（FR-01-3 间隔）。

### FR-14-4 浏览与下载
- **交互步骤**：① 共享中心点他人共享 → ② 浏览文件树 → ③ 勾选/全选 → ④ 「下载」→ ⑤ P2P 直连 owner 拉取（复用 FR-05/06）→ ⑥ 落本地默认下载目录（可改）。
- **界面元素**：共享浏览面板（目录树/文件列表/大小/哈希校验标）、下载进度（并入传输队列）。

### FR-14-5 共享方在线约束与误暴露防护
- **异常与边界**：
  - 共享方离线 → 下载失败提示「共享方不在线」（RK-08）。
  - 发布前确认弹窗强制（防误共享机密，RK-10）；可见性默认「指定人」而非「全部」（安全默认值）。
  - 大目录元数据膨胀 → 增量/分页（RK-09）。
- **细化验收**：Given A 发布共享，When B 经发现看到，Then 可浏览清单；Given 共享方离线，When B 下载，Then 失败提示；Given 指定人越权，When 请求，Then 拒绝。

## 16. 协议与数据格式细化

> 本章把「功能如何落地」的协议层讲清，供研发实现；不涉及加密（本期 Q3 内网可信）。

### 16.1 传输层分工
- **UDP**：同网段广播通告、SEED_PROBE/ANNOUNCE（发现层）。
- **TCP 直连**：所有业务数据（聊天、文件、共享字节、PEER_LIST、GROUP_*、SHARE_*）。

### 16.2 应用层信封（TCP 业务报文）
```
Envelope {
  proto_version: u8
  msg_id: string        // 全局唯一，用于 ACK 去重
  type: enum            // 见 16.5
  from: client_id
  to: client_id | group_id   // 单聊=对方；群聊=groupId；共享=owner_id
  ts: i64
  payload: bytes        // 按 type 解析
}
```
可靠性：TCP 本身保序；业务层对 FILE_DATA 按 chunk_seq 校验，缺块请求重传。

### 16.3 文件传输握手序列（FR-05/06/07/08）
```
SENDER                                      RECEIVER
  |-- TCP 直连 --------------------------------->|
  |-- FILE_META {file_id,name,size,hash,chunk} ->|
  |<-- FILE_ACK {ok|reject(reason)} -------------|
  |   (reject: 空间不足/超上限/拒绝)
  |-- [续传] RESUME_OFFSET {hash} -------------->|
  |<-- RESUME_RESP {received_offset} ------------|
  |-- FILE_DATA {chunk_seq, bytes}  (窗口 N) --->|
  |<-- CHUNK_ACK {seq} (每 N 块/超时) -----------|
  |-- FILE_DONE {whole_hash} ------------------->|
  |<-- DONE_ACK {ok|mismatch} -------------------|
  |   mismatch → 整体重传或断点重传（按设置）
```
控制信令：FILE_PAUSE / FILE_RESUME / FILE_CANCEL 双向，触发 FR-08 状态迁移（见 PRD 9.1）。

### 16.4 共享元数据 Schema（FR-14-3）
```json
{
  "share_id": "uuid",
  "owner_id": "client_id",
  "owner_tcp_port": 54218,
  "name": "周报模板",
  "visibility": {
    "type": "all" | "users" | "group",
    "allowed": ["client_id", ...]   // type=users/group 时填
  },
  "items": [
    { "path": "2026/W01.docx", "name": "W01.docx", "size": 12345, "hash": "sha256...", "mtime": 1696828800 }
  ],
  "created_at": 1696828800
}
```
传播：同网段随 UDP 通告携带摘要（share_id+name+owner+visibility+总大小+文件数）；跨网段经种子 PEER_LIST/ANNOUNCE 携带；完整 items 由下载方按需 SHARE_INDEX_REQ 拉取（防大目录膨胀，RK-09）。

### 16.5 消息类型枚举（type）
| type | 用途 | 关联 FR |
|------|------|---------|
| CHAT_TEXT | 文字消息 | FR-03 |
| CHAT_ACK / CHAT_READ | 送达/已读回执 | FR-03-2 |
| OFFLINE_FLUSH | 缓冲重投 | FR-04-2 |
| FILE_META / FILE_ACK / FILE_DATA / CHUNK_ACK / FILE_DONE / DONE_ACK | 文件传输 | FR-05/06 |
| FILE_PAUSE / RESUME / CANCEL | 传输控制 | FR-08 |
| PRESENCE | 上下线/状态广播 | FR-01-4 / FR-04-2 |
| SEED_PROBE / ANNOUNCE | 种子两跳 | FR-01-2 |
| PEER_LIST_REQ / RESP | 拉对端列表 | FR-01-2 |
| SHARE_INDEX_REQ / RESP | 共享元数据拉取 | FR-14-3/4 |
| SHARE_DOWNLOAD_REQ / DATA | 共享下载 | FR-14-4 |
| GROUP_CREATE / INVITE / REMOVE / LEAVE / DISBAND / MSG | 群组 | FR-13 |

## 17. 跨功能端到端交互流（主流程步骤）

### 17.1 首次跨网段聊天（新用户 A 找 B）
1. A 安装启动 → 自动同网段广播 + 读 seed 列表发 SEED_PROBE。
2. 种子回 ANNOUNCE + A 拉 PEER_LIST 得 B 地址。
3. A 在线列表出现 B（状态灯「跨网段经种子 1/1」）。
4. A 双击 B → 输入消息 → 发送 → TCP 直连送达 → B 收气泡（FR-03/11）。
5. 若 B 离线 → A 消息入本地缓冲，待双在线flush（FR-04）。

### 17.2 共享发布到跨网段下载
1. A 共享中心发布目录 → 确认弹窗（可见性=全部）→ 元数据生成。
2. 元数据随发现层到 B（跨网段经种子）。
3. B 共享中心见 A 的共享 → 浏览 → 勾选下载。
4. B P2P 直连 A 拉取（FR-14-4 + FR-05/06）。
5. 若 A 离线 → B 下载失败提示「共享方不在线」（RK-08）。

### 17.3 群组发送含离线成员
1. 群主建群（5 人，2 离线）。
2. 在线成员直投 ≤1s 收到。
3. 离线 2 人：发送端本地缓冲 → 二人上线且发送端在线 → flush 按序送达（FR-13-3 + FR-04）。
