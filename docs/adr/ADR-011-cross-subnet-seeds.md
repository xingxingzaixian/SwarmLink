# ADR-011：跨网段采用「每网段多种子 + 单跳目录拉取」，不设引导节点

**Status**：Accepted
**来源**：`架构设计书.md` §4.5.1 / §0.5

## Context

已确认 **3–5 个网段、种子手动维护**。UDP 广播止步于路由器，
3–5 个网段就是 3–5 个互不可见的「广播岛」。

候选方案三类：(A) 每网段配种子做单播目录拉取；(B) 设一个只读引导节点统一下发种子列表；
(C) 引入中继节点转发消息。

**B 与 C 都会长出「事实上的中心节点」**，与「无中心」这个核心卖点直接冲突。

## Decision

- 采用方案 **A**：**网段内广播 + 网段间种子单播 `PEER_LIST_REQ/RESP`**；
- 每网段配 **≥ 2 颗**种子（共 6–10 条 IP，手工维护）；
- **种子不具任何特权**：它与普通节点跑**完全相同的目录交换协议**，
  「特殊性」完全外置到配置文件。它产出的就是普通的 `peer.Announcement`，
  与广播产出的结构完全同构 → 走**同一条** Upsert 路径进入 `PeerDirectory`；
- 节点每轮**随机拉 2 颗**可达种子并合并响应（而非拉全部），避免种子热点；
- **不设引导节点、不设中继。**

## 第一跳必须走 UDP（容易写错的地方）

```
第 1 跳：UDP  →  节点向种子的 [ip:udp_port] 发带魔数的探测包
                 种子【单播】回一份自己的 ANNOUNCE（签名完整）
第 2 跳：TCP  →  节点从这份 ANNOUNCE 学到种子的实际 tcp_port / node_id / pub_key
                 据此 TCP 拨号做 PEER_LIST_REQ
```

**硬约束：被选为种子的机器必须固定 `udp_port`（关闭 ADR-008 的端口回退）。**
否则跨网段节点拿着配置里的端口发第一个报文就石沉大海，
而它没有任何其他途径知道种子换了端口（种子的广播同样不跨路由器）。

只有这一个端口需要固定；`tcp_port` 照样可以回退，由回传的 ANNOUNCE 学到 ——
因此 ADR-008 的端口回退机制不受影响。

种子身份**从第一跳起即可验证**（回传的 ANNOUNCE 带 Ed25519 签名），不给中间人留口子。

## 代价（必须承认）

**依赖两条部署前置条件** —— 它们是网络侧的既定事实，**代码救不了**：

| # | 前置条件 | 不满足的后果 | 自检方法 |
|---|---|---|---|
| **P-1** | 任意两网段的种子 IP 之间**可 TCP 直连**（三层路由可达，非 NAT 隔离） | 跨网段发现与消息全部失效，只能引入中继 | `swarmlink-cli --self-check` 对种子做探测与目录拉取 |
| **P-2** | 各网段使用**不重叠的地址段**（不得都是 `192.168.1.0/24`） | 目录中出现 node_id 不同、IP 相同的条目 → **跨网段寻址崩溃，且现象隐蔽、极难排查** | `ANNOUNCE` 携带 `subnet` 字段；M1 起即具备 |

> P-2 不是理论风险。**「多个厂区/门店各自一个 192.168.1.0/24，再靠 VPN 互联」
> 是内网组网里最常见的形态之一。**

## Consequences

**更好**

- 零特权、零状态，种子可随时替换增删；种子宕机不影响已建立的消息与传输；
- 只维护一条目录交换代码路径；
- 复用 ADR-010 的 `list_epoch` 后单颗种子出站 < 2 KB/s，**种子机器不需要任何特殊规格**；
- 跨网段首条消息**直接拨号，零跳数**。

**更差**

- 新节点跨网段可见有 ≤ 1 个刷新周期（默认 5 min）的延迟；
- 单颗种子失效会让该网段「对网段外暂时不可见」（靠 ≥ 2 种子缓解为「刷新变慢」）。

## 不采纳的替代

- **只读引导节点（B）**：最容易被做成「事实中心」，而 3–5 网段手工配种子根本不需要它；
- **中继转发（C）**：与「无中心」直接冲突，且 P-1 满足时完全不需要。**永久不做**；
- **种子广播转发跨网段目录**：12.8 KB 超 MTU，UDP 广播分片丢一片即全丢，不可控。

## 验证

`test/e2e.TestCrossSubnetConvergenceViaSeed`：
构造两个互不广播的域（A 域 `{a1}`，B 域 `{b1,b2}`）与一颗同时可达两域的种子，
**只允许通过种子的单跳目录交换收敛**，断言：

1. 种子从两个域学到条目（含 b2 —— 它是从 b1 的目录里间接学到的）；
2. `a1` 学到 `b1`/`b2`，`b1` 学到 `a1`（目录双向收敛）；
3. 学到的跨网段条目**带可拨号地址**、`source == seed`、`subnet` 非空；
4. 跨网段**首条消息直接拨号即可送达**，并有 ACK 回传。
