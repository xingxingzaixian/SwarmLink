## 二、背景与目标

### 2.1 背景
局域网内用户（同事 / 机房 / 实验室）高频需要**临时文字沟通**、**文件互传**与**文件共享**，现有方式（U 盘、微信、邮件）存在跨设备不便、需出公网、大文件受限等痛点。飞秋（FeiQiu）类工具"零服务器、广播发现"解决同网段，但**不支持跨网段/VLAN**且功能老旧。本产品目标：在保留"轻量、零常驻服务"理念的同时，以**种子机制**支持跨网段，并补齐现代体验（断点续传、历史记录、批量发送、文件共享）。

### 2.2 要解决的问题
1. 同网段可聊可传，但跨网段/VLAN 无法互通。
2. 大文件传输中断需从头重传，成本高。
3. 无历史记录，换机器/重装后记录丢失。
4. 批量文件发送不便。
5. 缺少"发布目录、他人浏览下载"的文件共享能力。

### 2.3 成功指标与口径
| 指标 | 目标值 | 口径 / 统计周期 |
|------|--------|----------------|
| 首次文件发送操作步数 | ≤3 步（选中→拖入→发送） | 估算，待实测 |
| 文字消息端到端延迟 | <1s（P2P，同网络） | P95，估算 |
| 1GB 文件传输成功率 | ≥99% | 成功率 = 完成数 ÷ 发起数，7 日滚动 |
| 跨网段发现成功率 | ≥99% | 经种子成功发现对端/共享 的比例 |
| 断点续传恢复成功率 | ≥99% | 主动断开后重连续传，估算 |
| 在线列表刷新时延 | <2s（状态变更后） | P95，估算 |

> 注：除标注"实测"外均为**估算**，上线后首月以埋点复核并修订目标。

## 三、名词与术语定义

| 术语 | 定义 |
|------|------|
| 种子（Seed） | 配置于客户端 seed 列表中的**普通节点**（IP:UDP/TCP 端口），无特权；负责跨网段发现引导。两跳：UDP 探测通告（SEED_PROBE/ANNOUNCE）+ TCP 拉对端列表（PEER_LIST）。任何普通节点均可被配置为种子；connected UDP socket 天然防伪造。 |
| 文件共享（File Share） | 将本地目录/文件发布为可被他人浏览下载的资源；元数据经发现层传播，字节 P2P 直连拉取。 |
| P2P 直连 | 两客户端之间直接建立 TCP 连接传输数据，不经任何第三方。 |
| 网段 / VLAN | 二层或三层隔离的网络区域；跨网段指不在同一广播域。 |
| 离线消息（本地缓冲） | 接收方不在线时，发送端在**本机本地**暂存，待"发送端自身在线且检测到接收方上线"才投递。 |
| 在线列表 | 当前经发现层（广播+种子）可见的其他客户端与共享清单。 |
| 中继（Relay） | 本期**不采用**集中式中继/服务器；仅作为后续可选的"文件兜底转发通道"概念（本期未采纳，决策 a）。 |

## 四、需求范围

### 4.1 包含（本期）
- 主机发现与在线状态（同网段 UDP 广播 + 跨网段种子两跳发现）
- 单聊文字消息（含离线消息本地缓冲与双在线投递）
- 群组聊天（多对多群聊，含群内离线本地缓冲与投递）
- 点对点文件发送（P2P 直连，阻断即失败提示，无兜底）
- 文件共享（目录发布 + 元数据发现 + P2P 拉取 + 可见性控制）
- 大文件断点续传
- 拖拽批量发送
- 传输进度 / 暂停 / 取消 / 失败重试
- 历史记录本地持久化与查看
- 种子列表配置与连接管理
- 消息通知（托盘气泡 / 声音）
- 系统托盘驻留、最小化、开机自启

### 4.2 不包含（本期 · 后续版本池）
- 传输加密与身份认证（Q3 默认内网可信，后续版本加 TLS + 设备鉴权）
- 公网穿透（本期聚焦跨网段；纯公网远程访问列入后续）
- 文件兜底转发（防火墙/NAT 阻断时的中继转发，决策 a 不选）
- 共享离线托管（共享方离线时由服务器托管文件，本期不做）
- 语音 / 视频通话
- 远程控制 / 屏幕共享
- 服务端集中历史漫游（本期仅客户端本地历史）
- 管理后台 / 审计日志

## 五、方案对比与选型说明

| 方案 | 思路 | 成本 | 复杂度 | 体验 | 风险 | 结论 |
|------|------|------|--------|------|------|------|
| A 经典广播型 | 仅 UDP 广播发现 + TCP 直连 | 低 | 低 | 同网段好，跨网段不可用 | 跨网段不支持 | 否决（不满足 Q1=c） |
| B 混合中继型 | 集中式中继发现/路由 + 离线存储 | 中 | 中 | 跨网段可达、支持离线 | 中继单点、常驻服务、同网段也依赖它 | 否决（用户有更优种子实现） |
| **D 种子发现型** | 种子两跳发现 + 同网段广播兜底 + 数据面全 P2P + 发送端本地离线队列 | 低 | 中 | 跨网段可达、零常驻服务器、离线靠本地队列 | 共享方需在线、P2P 阻断无兜底 | **本期采用** |

**推荐：方案 D。** 理由：
- 满足跨网段刚需（Q1=c），且**无需任何常驻服务器**——种子是配置里的普通节点，契合"类飞秋零部署"。
- 离线消息改为**发送端本地缓冲 + 双在线投递**，不依赖服务器存储，与 D 架构天然契合。
- 文件发送/共享均为 P2P 直连，性能最优；防火墙阻断即明确失败（决策 a，不引入兜底复杂度）。
- 用户已有成熟的种子机制实现（两跳 UDP 探测 + TCP 拉列表、connected UDP 防伪造），技术风险低、可直接复用。

**演进路径**：本期 D（种子+广播+本地离线+共享）→ 后续：传输加密 → 共享离线托管 → 公网穿透。

## 六、用户角色与使用场景

### 6.1 用户角色
| 角色 | 说明 | 能力水平 |
|------|------|----------|
| 普通用户 | 局域网内聊天/传文件/共享的成员 | 新手~熟练 |
| 部署协助者（IT） | 建议并配置跨网段可达的种子节点列表 | 熟练（IT） |

### 6.2 使用场景
- **场景 1（主流程）**：用户在办公室，拖动 3 个设计稿到同事头像，自动批量发送，对方实时收到并保存。
- **场景 2（跨网段）**：研发与测试分属不同 VLAN，经种子互相发现并互联，照常聊天与传包。
- **场景 3（本地缓冲离线）**：下班后给用户 A 发消息，A 不在线；消息存于发送端本地。次日 A 上线且发送端在线，发送端自动把消息推给 A。
- **场景 4（大文件中断）**：传 4GB 镜像时网络抖动断开，用户重连后从断点续传，无需重头。
- **场景 5（群组）**：项目组 8 人建群，2 人离线；群内发需求文档，发送端对在线成员直投、对离线成员本地缓冲；离线两人上线后由发送端投递，无遗漏。
- **场景 6（文件共享）**：A 发布"周报模板"目录（可见性=全部），跨网段的 B 经种子发现该共享，P2P 直连拉取，支持断点续传。

## 七、功能需求

> 状态词约定：必须（shall）/ 应该（should）/ 可以（may）/ 禁止（must not）。

### FR-01 主机发现与在线状态（广播 + 种子双通道）
- 规则：
  - 同网段：必须支持 UDP 广播发现，节点上线即广播自身（昵称、IP、版本、TCP/UDP 端口、状态）。
  - 跨网段：必须支持向 seed 列表中的种子节点发起两跳发现（UDP SEED_PROBE → ANNOUNCE；TCP PEER_LIST_REQ → PEER_LIST_RESP），学习对端地址。
  - 每 N 秒（默认 15s，可配）心跳；超时（默认 45s）标记离线。
  - 禁止只依赖单一发现通道——任一通道失效，另一通道仍可工作（同网段广播兜底 / 跨网段种子）。
- 验收（GWT）：
  - Given 同网段两客户端，When 一方启动，Then 另一方在 ≤2s 内出现在在线列表。
  - Given 跨网段且配置正确种子，When 启动，Then 在 ≤3s 内经种子互相发现。
  - Given 所有种子不可达但同网段可达，When 启动，Then 同网段内仍正常发现。

### FR-02 在线列表与共享清单展示
- 规则：客户端必须展示在线用户列表（昵称、状态：在线/离线/忙碌）与共享清单（共享名、owner、可见性）；状态/共享变更实时刷新（<2s）。
- 验收：Given 某用户状态或共享变化，When 发现层更新，Then 本地列表在 2s 内更新。

### FR-03 单聊文字消息
- 规则：必须支持两人文字聊天；消息含发送时间、已送达/未送达状态；接收方不在线时转本地缓冲（见 FR-04）。
- 验收：
  - Given 双方在线，When 发送消息，Then 对方在 1s 内收到并回执"已送达"。
  - Given 含特殊字符/超长文本（≤5000 字），When 发送，Then 完整显示无截断。

### FR-04 离线消息（发送端本地缓冲 + 双在线投递）
- 规则：
  - 接收方不在线时，发送端必须在本机本地存储待发消息（不依赖任何服务器/中继）。
  - 当且仅当"发送端自身在线"且"检测到接收方上线"时，发送端必须自动推送缓冲消息（单聊与群聊通用）。
  - 缓冲保留期默认 30 天（可配）；发送端应标记"待投递"状态。
  - 边界（已知取舍，见 RK-08）：若发送端在接收方上线前也已离线，消息等待至双方再次同时在线才投递。
- 验收：
  - Given 接收方离线，When 发送 5 条消息，Then 存于发送端本地，接收方在线前不送达。
  - Given 接收方上线且发送端在线，When 缓冲存在，Then 5 条按序送达，待投递计数清零。
  - Given 发送端在接收方上线期间也离线，When 双方再次同时在线，Then 缓冲最终送达。

### FR-05 文件发送（P2P 直连，阻断即失败）
- 规则：发送文件必须尝试与接收方 P2P 直连传输；单文件大小上限默认 10GB（可配）；禁止经任何中继/服务器转发（本期不提供兜底，决策 a）。直连不可达（防火墙/NAT 阻断、对方离线）时，必须明确提示失败原因，禁止静默。
- 验收：
  - Given 双方网络可达，When 发送文件，Then P2P 直连完成，不经第三方。
  - Given 一方在防火墙后不可直连，When 发送文件，Then 失败并提示"直连失败（可能被防火墙/NAT 阻断）"，建议检查端口或网络。

### FR-06 大文件断点续传
- 规则：传输中断（断网/取消/失败）后，重发同一文件（同路径+大小+哈希）必须支持从已传偏移续传；应该展示续传起点。
- 验收：Given 已传 40% 时断开，When 重发同文件，Then 从 40% 偏移继续，总耗时显著少于从零传。

### FR-07 拖拽批量发送
- 规则：必须支持将多个文件/文件夹从资源管理器拖入会话窗口批量发送；应该显示批量队列与总进度。
- 验收：Given 拖入 10 个文件，When 确认发送，Then 进入队列依次传输，总进度正确，失败项可单独重试。

### FR-08 传输进度 / 暂停 / 取消 / 重试
- 规则：传输中必须展示速度、进度百分比、剩余时间（估算）；必须支持暂停与取消；失败后必须支持重试（触发续传）。
- 验收：Given 传输进行中，When 点击暂停，Then 停止且可恢复；When 点击取消，Then 清理临时文件且不残留。

### FR-09 历史记录本地持久化与查看
- 规则：必须本地持久化聊天与传输记录（含时间戳）；应该支持按联系人/共享筛选与关键词搜索；禁止明文外泄至公网。
- 验收：Given 重装/重启客户端，When 打开历史，Then 本地记录完整可查（依赖本地存储未损坏）。

### FR-10 种子列表配置与连接管理
- 规则：必须提供种子节点列表（IP:端口，可多条）配置入口；种子不可达必须自动尝试下一颗并提示；同网段广播开关应可配；连接状态需可视化。
- 验收：Given 配置 2 个种子、其一宕机，When 客户端启动，Then 自动使用另一颗完成跨网段发现。

### FR-11 消息通知
- 规则：收到新消息/文件必须触发托盘气泡与可选声音；应该支持免打扰时段。
- 验收：Given 收到新消息且窗口非聚焦，When 消息到达，Then 弹出托盘气泡。

### FR-12 系统驻留与自启
- 规则：应该支持最小化到托盘、开机自启（可关）；禁止强制自启且无关闭入口。
- 验收：Given 勾选开机自启，When 系统重启，Then 客户端自动运行并驻留托盘。

### FR-13 群组聊天（多对多群聊）
- 规则：
  - 必须支持创建群组（命名、指定群主）；必须支持邀请/移除成员（仅群主可移除，可配）。
  - 群消息：发送端必须向每个在线成员 P2P 直连投递；成员离线时按 FR-04 本地缓冲，待其上线且发送端在线时投递。
  - 应该支持向群组发送文件（复用 FR-05，目标为群组，P2P 直连）。
  - 应该支持群成员管理视图、群历史查看（本地持久化，复用 FR-09）。
  - 群解散（群主）后，必须停止后续消息路由并提示成员。
- 验收（GWT）：
  - Given 群主创建含 5 名成员的群，When 发送群消息，Then 全部在线成员在 1s 内收到。
  - Given 群内某成员离线，When 发送群消息，Then 发送端本地缓冲，该成员上线且发送端在线后收到未读且按序。
  - Given 群主移除某成员，When 移除生效，Then 该成员不再接收后续群消息。
  - Given 群主解散群组，When 解散，Then 所有成员收到解散提示且不再收到群消息。

### FR-14 文件共享（目录发布 + P2P 拉取）
- 规则：
  - 必须支持将本地一个或多个目录/文件发布为"共享"，可设可见性（全部可见 / 指定人 / 仅群组）。
  - 共享元数据（共享名、文件清单、大小、哈希、owner、可见性、owner TCP 端口）必须经发现层传播：同网段走 UDP 广播，跨网段走种子（PEER_LIST/ANNOUNCE 携带共享索引）。
  - 下载方必须能浏览共享列表并 P2P 直连共享方拉取文件，复用 FR-05 传输引擎与 FR-06 断点续传；禁止经中继转发。
  - 共享方必须在线方可被下载；共享方离线时下载必须失败并提示"共享方不在线"。
  - 可见性校验：下载请求必须校验请求方是否在可见范围，越权访问必须拒绝。
  - 共享前必须弹出确认，明示将被他人可见的文件范围（防误共享敏感文件）。
- 验收（GWT）：
  - Given A 发布共享目录，When B 经发现看到该共享，Then B 可浏览文件清单。
  - Given B 发起下载且共享方在线、网络可达，When 下载，Then P2P 拉取完成并支持断点续传。
  - Given 共享方离线，When B 下载，Then 失败并提示"共享方不在线"。
  - Given 共享设为"指定人"且 C 不在名单，When C 请求，Then 被拒绝。

## 八、非功能需求

| 类别 | 需求 | 数值 / 要求 |
|------|------|------------|
| 性能 | 在线列表刷新 | 状态/共享变更后 <2s（P95） |
| 性能 | 消息延迟 | <1s（P2P，同网络，P95） |
| 性能 | 文件成功率 | 1GB ≥99% |
| 性能 | 跨网段发现成功率 | ≥99% |
| 性能 | 并发传输 | 单客户端至少 5 路并发 |
| 兼容 | 平台 | 以 Windows 为主；架构应支持跨平台（Win/mac/Linux）以便后续 |

| 可访问性 | 基础 | 关键操作键盘可达；托盘/弹窗文案无歧义 |
| 资源 | 客户端 | 常驻内存 <150MB（估算） |
| 可靠 | 发现 | 种子多节点配置 + 同网段广播兜底，无单点 |

## 九、业务流程与状态流转

### 9.1 文件传输状态机（发送/共享下载通用）
```
状态集合：空闲 → 连接中 → 传输中 → 已暂停 → 已完成 / 失败 / 已取消
触发事件：发起 / 直连成功 / 直连失败(防火墙/NAT/离线) / 暂停 / 恢复 / 完成 / 出错 / 取消
迁移约束：
- 空闲 --发起--> 连接中
- 连接中 --直连失败--> 失败（提示原因，无兜底）
- 传输中 --暂停--> 已暂停 --恢复--> 传输中
- 传输中 --完成--> 已完成；--出错--> 失败 --重试--> 连接中
- 任意 --取消--> 已取消
```

### 9.2 消息状态（本地缓冲模型）
```
发送中 → 已送达（对方在线回执） / 已缓冲（对方离线，存本机，待双在线） → 已读（可选）
失败/未达 → 留本地缓冲，待双在线重投
```

### 9.3 发现连接状态
```
种子连接：断开 → 连接中 → 已连接（拉到 PEER_LIST） → 重连中（退避，尝试下一颗种子）
同网段广播：常开，独立于种子；种子全失效时仍保同网段可用
```

## 十、数据与埋点需求

### 10.1 核心实体
- 用户（Client）：id、昵称、IP、版本、状态、最后心跳、TCP/UDP 端口
- 群组（Group）：id、名称、群主、成员列表、创建时间、状态（活跃/解散）
- 共享（Share）：id、owner、文件清单、可见性（全部/指定人/群组）、owner TCP 端口、状态
- 消息（Message）：id、from、to（单聊=对方 id / 群聊=groupId）、类型、内容/文件元数据、状态（含"已缓冲"）、时间戳
- 传输任务（Transfer）：id、文件哈希、大小、偏移、状态、路径、目标类型（单聊/群组/共享）

### 10.2 埋点（最小数据能力 · 本期至少 1 看板）
| 事件 | 触发时机 | 上报字段 |
|------|----------|----------|
| transfer_start | 发起传输 | file_size、类型(单聊/群组/共享)、时间戳 |
| transfer_complete | 完成 | 耗时、平均速度、是否续传 |
| transfer_fail | 失败 | 失败原因（阻断/离线/取消）、阶段 |
| msg_send | 发消息 | 类型、是否进入本地缓冲、延迟 |
| group_msg_send | 发群消息 | 群规模、在线成员数、缓冲成员数、延迟 |
| seed_discover | 跨网段发现 | 种子结果、耗时、发现对端数 |
| share_download | 共享下载 | 共享规模、是否续传、结果 |

### 10.3 指标口径
- 文件成功率 = 完成数 ÷ 发起数（7 日滚动）
- 跨网段发现成功率 = 经种子成功发现对端/共享次数 ÷ 跨网段发现尝试次数
- 平均传输速度 = Σ文件大小 ÷ Σ耗时

## 十一、权限与安全要求

| 角色 | 功能权限 | 数据权限 |
|------|----------|----------|
| 普通用户 | 聊天、发文件、发布/下载共享、配置种子列表 | 仅本人历史、本人本地缓冲与本地共享 |
| 部署协助者（IT） | 建议/配置跨网段种子节点 | 仅种子节点运行态（不含用户消息明文） |

安全要求：
- 本期默认内网可信，**不**做端到端加密（Q3 决策）；但所有消息/文件内容禁止明文推至公网。
- 共享必须做**可见性控制 + 发布前确认弹窗**，防止误共享敏感文件（见 RK-11）。
- 发送端本地离线缓冲仅存于本机，禁止外泄。
- 后续版本必须补：传输 TLS 加密、设备身份鉴权、共享访问审计。

## 十二、异常处理清单

| 异常 | 处理 |
|------|------|
| 所有种子不可达 | 自动尝试下一颗；提示"跨网段发现受限"，同网段广播仍可用 |
| P2P 直连失败 | 明确提示"直连失败（防火墙/NAT 阻断或对方离线）"，建议检查端口/网络；不静默 |
| 共享方离线 | 下载失败并提示"共享方不在线" |
| 共享越权访问 | 校验可见性，拒绝并提示无权限 |
| 磁盘空间不足 | 传输前预检；不足时中止并提示 |
| 文件被占用/删除 | 发送/共享前校验；失败提示并允许重试 |
| 网络抖动中断 | 触发续传；超过 N 次失败标记失败 |
| 超大文件超上限 | 拒绝并提示上限值 |
| 发送端损坏/重装 | 本地离线缓冲与本地共享配置可能丢失（见 RK-08），提示用户备份 |

## 十三、上线计划、依赖与上线后验证

### 13.1 依赖评估
| 依赖项 | 所属 | 就绪状态 | 分级 | 最晚就绪 | 替代方案 |
|--------|------|----------|------|----------|----------|
| 种子节点（建议 ≥1 个跨网段可达的普通节点/固定 IP） | 运维/用户 | 待确认 | 并行 | 内测前 | 同网段 UDP 广播兜底，无种子也能同网段工作 |
| 防火墙放行 P2P 端口 | 网络 | 待确认 | 并行 | 内测前 | 端口可配置，先选已放行端口 |
| 客户端打包/签名环境 | 研发 | 待确认 | 并行 | 公测前 | 先内部测试包 |

### 13.2 上线计划
- MVP 闭环：种子列表配置 → 客户端发现（广播+种子）→ 单聊/群聊 → 文件发送/共享 → 历史/续传/批量 → 内测。
- 灰度：先单部门内测（同网段）→ 跨网段扩大（配种子）→ 公测。
- 回滚：客户端支持旧版共存；种子节点为普通节点，无状态，回滚无负担。

### 13.3 上线后验证
- 首月复核第二章成功指标（埋点看板）。
- 跨网段连通性专项测试（≥2 个 VLAN，验证种子两跳发现）。
- 共享场景验证：跨网段发现共享 → P2P 下载 → 断点续传。

### 15.1 原型思路（线框描述）
- **主窗口**：左侧在线列表（昵称+状态）与群组列表（群名+未读数）、共享清单（共享名+owner）；右侧会话区（消息流 + 输入栏 + 发送按钮 + 拖拽区）；底部传输队列浮层（进度/暂停/取消）。

- **共享发布确认弹窗**：明示将被可见的文件范围与可见性，确认后方可发布。
